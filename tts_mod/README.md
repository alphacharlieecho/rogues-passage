# Tabletop Simulator scripts — planned

The catalog builder exports data for this folder to consume in a later milestone.

Planned Lua modules:
- `Global.lua`: campaign state and saved data
- `PlayerManager.lua`: player setup and two-color choice
- `DeckManager.lua`: import/shuffle cards and manage starter pools
- `Economy.lua`: coins, shop, and infusions
- `DuelManager.lua`: match lifecycle, rewards, cleanup, and next opponent

The first milestone intentionally does not create placeholder Lua logic that might be mistaken for a working mod.
